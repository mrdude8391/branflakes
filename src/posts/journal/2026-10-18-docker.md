### Why docker? It's purpose

You develop and write code locally. When you want to run the code somewhere else, you use Docker. For example your fast-api backend server. When you move to a new computer, you need to first install and set up `python`, create the `venv`, install all the packages from `requirements.txt`, and then start the `venv`, and then start the server either with `uvicorn src.main:app --reload`. When the backend is uploaded to a cloud machine on AWS how do you tell the machine to do all these things? Docker.

### Docker-Compose.yml file

To run a Docker Compose file. Such as the `docker-compose.test.yml` file for my pytests. `cd` to the folder of the file. `-f` to specify the exact file name and location (ie. if it's named anything other than `docker-compose.yml`). `-d` to run the detached, when you run a container in detached mode, it means the containers run in the background of your terminal. Without it, you will see a live stream of all log outputs from the containers.

```bash
docker compose up
docker compose -f .\docker-compose.test.yml up -d
```
