### Creating tables

```sql
CREATE TABLE companies (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name VARCHAR(200) NOT NULL,
    website VARCHAR(500)
);
```

### Inserting Values

```sql
INSERT INTO companies (name, website)
VALUES
    ('Google', 'https://google.com'),
    ('Microsoft', 'https://microsoft.com'),
    ('Amazon', 'https://amazon.com');
```
