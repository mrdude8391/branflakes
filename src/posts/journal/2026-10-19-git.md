## New Features (branching)

If you want to add a new feature and branch.

```bash
# Create a feature branch
git switch -c feature/my-new-feature

# Make changes, then commit
git add .
git commit -m "Add my new feature"

# Push the branch to GitHub
git push -u origin feature/my-new-feature
```

### 1. Create branch

```bash
# Create Branch
# modern git
git switch -c <branch-name>
# legacy
git checkout -b <branch-name>
```

```bash
# Change Branch
git switch <branch-name>
git checkout <branch-name>
# See all local branches
git branch
# See all branches, local and remote
git branch --all
# Rename Branch. -m to safe rename. -M to force rename. Omit old-name renames current branch
git branch -m <old-name> <new-name>
```

### 2. Develop, Test, & Commit

```bash
git add .
git add ./file-name.file
git commit -m "stuff"
```

### 3. Push Branch

```bash
# connect local branch to GitHub branch. -u sets upstream. origin specifies name of remote repository.
git push -u origin <branch-name>
git push
```

### 4. Create Pull Request (PR) on GitHub

This step is done on GitHub. Merge the development branch to `main`

### 5. Update Main Locally

```bash
git switch main
git checkout main
git pull origin main
```

### 6. Delete Branch

```bash
# Delete Local. -d to delete. -D uppercase to force-delete
git branch -d <branch-name>
# Delete Remote
git push origin --delete <branch-name>
```

## New Repo

If you are creating a new repo, or connecting a repo.

### 1. Initialize Git (if not already)

```bash
git init
git add .
git commit -m "Initial commit"
# -M forces rename of current branch
git branch -M main
```

### 2. Connect local repo to GitHub

Get the GitHub repo URL from Github.

```bash
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
# Verify connection
git remote -v
```

### 3. Push To GitHub

```bash
# -u sets upstream. Tracking local main with remote main.
git push -u origin main
# Rename if needed
git branch -M main
```
